This project introduces **C++ containers, iterators, and algorithms** through three exercises.

- **Exercise 00 — Easyfind:** Implements a function to find a value in a container.
- **Exercise 01 — Span:** Stores numbers and calculates the shortest and longest spans between them.
- **Exercise 02 — MutantStack:** Extends the standard stack by providing iterators to access and traverse its elements.

The project focuses on working with the **STL (Standard Template Library)** and templates in C++.

## Instructions

Compile the exercises using Make:

```bash
make
```

Run the corresponding executable for each exercise:

```bash
./ex00
./ex01
./ex02
```

Clean the generated files:

```bash
make clean
```

Remove all compiled files and executables:

```bash
make fclean
```

The project is written in **C++** and uses a **Makefile** for compilation.
